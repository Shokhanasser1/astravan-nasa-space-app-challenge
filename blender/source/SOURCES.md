# Sources

All assets were downloaded from the claude.ai artifact "Oy karvonsaroyi Model Studio" (https://claude.ai/artifact/Ek9cnnwNRukSymbkfEbGC7) and decoded from base64 to binary GLB.
Model titles below are descriptive names for each model id.

General source: NASA 3D Resources — https://github.com/nasa/NASA-3D-Resources and https://science.nasa.gov/3d-resources/<name>.

## Brand rules

NASA media is generally free to use, but the NASA insignia (meatball), logotype (worm), seal, flags and mission patches may NOT appear in game art.
Known logo/flag carriers (artifact): hdu-1, hdu-2, astronaut, saturn-v (painted in textures); emu (hide materials using emusuitFLAGpatch, emusuitvitruvianpatch, emusuitbox4); mark-3 (hide texturelogo).
Also found during inventory (visual sweep): apollo-lm (US flag + 'UNITED STATES'), curiosity (tex_05: NASA meatball, lettering), perseverance (arm_graphics, blade: NASA + JPL logos, US flag, lettering), gateway (DSXR: 'Canada' wordmark). See INVENTORY.md.
