# blender/lander_v2 — yangi Oy kemasi (lander), kabinasi va animatsiyalari bilan

**Kim:** Samandar (Claude Code agentlari, Blender 5.3). **Qachon:** 15.11.2026 kechasi. **O'yin build'iga kirmaydi**
(`public/` dan tashqarida): bu video, pitch va keyingi ishlar uchun manba.

> EN: A new lunar lander built procedurally by Blender Python scripts after the team's concept images (gold-foil
> descent stage, white faceted cabin, big mesh dish on the left, robotic arm on the right, front ladder, porch and
> hatch), with a walk-in cabin (instrument panel, screens, switches, pressable buttons), moving parts (hatch, buttons,
> launch cover, panel boot, arm, dish), astronaut clips for the ladder, the hatch and the buttons, the Moon scene and
> the "step 5" still of the team's video, and an animated sequence. **AI-made model:** the geometry and materials are
> generated by code that Claude Code wrote (not NASA-derived, not an AI image); see `docs/AI-USE.md`.
> The `.blend` files and full-size renders are **not in git**: GitHub Release
> [`lander-v2-2026-11-15`](https://github.com/Shokhanasser1/astravan-nasa-space-app-challenge/releases/tag/lander-v2-2026-11-15).

## Skriptlar (qayta qurish)
- `SPEC.md` — barcha o'lchamlar (narvon pog'onalari, eshik, tugmalar koordinatalari): qismlar orasidagi kelishuv.
- `build_lander_v2.py` (bosh skript) → `exterior.py` (tashqi qism), `interior.py` (kabina) → `lander_v2.blend`.
- `scene_moon.py` (Oy sahnasi, 5-qadam surati), `sequence.py` (ketma-ketlik).
- Astronavt kliplari: `blender/game3d/characters/anim/clips_lander/` (LadderMount, LadderUp, LadderUpTop,
  LadderTopOut, LadderDown, PressHatchExt, EnterHatch, PressPanelC/L/R, PressLaunch). O'yin GLB'iga **kirmaydi**:
  `bake_all.py -- --clips-dir clips_lander` bilan alohida bake qilinadi.
- Skriptlardagi mutlaq yo'llar Samandarning ish papkasiga qaraydi (`~/dev/oy-karvonsaroyi-3d/hb7/lander_v2`,
  `game3d/characters/_work/astronaut_rig.blend`, `game3d/assets/earth-globe.glb`): boshqa kompyuterda shu yo'llarni
  o'zgartiring yoki Release'dagi `.blend` larni oching. Blender 5.3, `-b --factory-startup`, Cycles CPU ham ishlaydi.

  panelga 3–10 mm kiradi (tugma 1.5 sm chiqib turadi).
- Kostyumdagi to'q sariq chiziqlar faqat sahna fayllaridagi material nusxasida (o'yin modelida yo'q).

- Narvondan tushish (LadderDown) faqat pastki pog'onalar uchun; ayvondan narvonga o'tish klipi yo'q.
- Kema o'yinda ishlatilmaydi (o'yinda ASTRA'ning lander'i); o'yin uchun kerak bo'lsa, past poligonli nusxa + `npm run glb` kerak.
