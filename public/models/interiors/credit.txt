Building interiors (habitat, greenhouse, lab/workshop, lander): modelled from scratch in Blender 5.3 by Claude Code
(AI-made, team-directed), 15 Nov 2026, for HOME BY SEVEN. Layout, sizes and colours from NASA technical reports (NTRS)
and the NASA Image and Video Library, each fact listed with its API request and document id in
blender/interiors/<building>/SOURCES.md. No NASA imagery, logos or insignia are in the models.
Not endorsed by NASA.

hdu_habitat.glb, hdu_lab.glb, hdu_greenhouse.glb (15 Nov 2026, `?hdu`): the furnished walk-in interiors of the three
HDU modules of the base core (public/models/nasa-outpost/hdu_complex.glb), real size, each in its module's frame
(centre, door at +z): eight sections round an open middle after NASA's HDU papers on NTRS (habitat: GeoLab glovebox,
telerobotics, medical, galley, workshop, hygiene, the entry with suits; lab: workbenches and screens; greenhouse:
lettuce racks, four lettuce sets by garden level), the X-Hab loft with a centre ladder, outer and inner doors with
`DoorOpen`, `DoorOpenOuter`, `DoorOpenInner` clips. Modelled by Blender Python written with Claude Code (AI-made,
team-directed) in the team's oy-karvonsaroyi-3d/hb7/hdu_base/build_game_complex.py (SOURCES.md there); no NASA
imagery, logos or insignia in them. Web-converted with gltf-transform as in `npm run glb` (meshopt, WebP textures
<= 1024) plus --join false --flatten false --palette false (the contract's node and material names kept).

the same SOURCES.md for the habitat's hygiene section (the first `?hdu` habitat interior used it; this build's script
models the hygiene section in plain boxes).
