# HOME BY SEVEN — задачи участников (подробно)

Источник: итоговая версия (*Yakuniy versiya*) + Dizayn 2.0 + руководство разработчиков. Порядок и ворота —
`docs/PLAN.md`, правила работы — `CLAUDE.md`. Время ташкентское; оценки времени примерные.

**Главное правило:** каждый работает только в своих папках. Нужно изменить чужой файл — напиши владельцу,
что именно и зачем. Так пятеро не ломают друг другу работу.

---

## 0. Всем, первые 15 минут

1. Скачать проект и запустить:
   ```
   git clone https://github.com/Shokhanasser1/astravan-nasa-space-app-challenge.git
   cd astravan-nasa-space-app-challenge
   npm install
   npm run dev
   ```
   Откроется http://localhost:5173. Строку `Network: http://192.168…` из терминала открыть на телефоне (та же Wi-Fi).
2. Запустить Claude Code в папке проекта: `claude`. Он сам прочитает `CLAUDE.md` и правила своей папки.
   Первое сообщение — готовое, в разделе каждого участника ниже.
3. Ритм работы с git (каждые 30–60 минут):
   ```
   git pull --rebase
   npm run verify          # проверки + типы + тесты + сборка; красное — не пушим
   git add <свои файлы>
   git commit -m "feat: что сделано"
   git push
   ```
   Если `push` отклонён — `git pull --rebase`, потом снова `git push`. Никогда `push --force`.
4. Перед задачей больше одного файла — короткая спецификация в `docs/specs/` (цель, входы, выходы, проверка),
   показать её человеку, потом код. Claude это знает: просто скажи «сначала спецификация».
5. Тексты для игрока пишут люди (Аминжон). Агенты добавляют только ключи с пустым значением `""`.

**Ворота:** G2 сб 20:00 — семь дней на телефоне от начала до конца · G3 вс 09:00 — контент на месте ·
G4 вс 11:00 — заморозка · G5 вс 13:00 — отправлено.
