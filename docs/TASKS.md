# HOME BY SEVEN — карточки задач (14.11, 16:00)

Цель: **полноценная веб-игра для детей** (7–14 лет, основная аудитория 7–12), в которую ребёнок играет сам — на
телефоне или ноутбуке, без помощи взрослого. Источник решений: итоговая версия (*Yakuniy versiya*), `CLAUDE.md`.
Порядок и ворота — `docs/PLAN.md`. Трекер готовности — таблица «HOME BY SEVEN Readiness» (ссылку даёт Шохжахон-ака).

**Главное правило:** у каждого своя основная зона, но ни человек, ни Claude ею не ограничены: нужно — меняй любой
файл; сначала `git pull --rebase`, коммит маленький, в сообщении — чья это зона, и предупреди владельца.

**Ворота:** G2 сб 20:00 — семь дней на телефоне от начала до конца · G3 вс 09:00 — контент на месте ·
G4 вс 11:00 — заморозка · G5 вс 13:00 — отправлено.

## 0. Всем, первые 15 минут

1. Скачать и запустить:
   ```
   git clone https://github.com/Shokhanasser1/astravan-nasa-space-app-challenge.git
   cd astravan-nasa-space-app-challenge
   npm install
   npm run dev
   ```
   Откроется http://localhost:5173. Адрес `Network: http://…:5173` из терминала открыть на телефоне (та же Wi-Fi).
   Игра уже проходится от старта до экрана правды. Вместо слов пока видны ключи (`ui.board.confirmDay`) — это нормально.
2. Запустить Claude Code в папке проекта: `claude`. Первое сообщение — в твоей карточке ниже.
3. Каждые 30–60 минут:
   ```
   git pull --rebase
   npm run verify          # проверки + типы + тесты + сборка; красное — не пушим
   git add <свои файлы>
   git commit -m "feat: что сделано"
   git push
   ```
   `push` отклонён — снова `git pull --rebase`, потом `git push`. Никогда `push --force`.
4. Задача больше одного файла — сначала короткая спецификация в `docs/specs/`, показать человеку, потом код.
5. Тексты для игрока может писать и человек, и Claude; всё, что написал AI, отмечается в `docs/AI-USE.md`.

### Полноценная 3D-игра: персонаж, геометрия, физика (решение команды 14.11, вечер)

- **Разрешено и в работе:** играбельный астронавт, ходьба, столкновения, физика (прыжок при лунной гравитации
  1,62 м/с²), полная геометрия и анимации, модели из Blender.
- **Как, чтобы не сломать G2:** всё новое — за флагом `features.character` (`src/config/features.ts`, сейчас `false`).
  Пока новая версия не проходит неделю на телефоне, на G2 и на ссылке остаётся нынешняя играбельная версия.
- **Физика:** Rapier через `@react-three/rapier` (пакет добавляет Шохжахон-ака). Коллайдеры — простые формы
  (капсула, коробки), не по сетке модели. Подробно — `.claude/rules/three.md`, раздел «Character and physics».
- **Бюджет телефона тот же:** < 100 тыс. треугольников и ~50 вызовов на кадр, модели ≤ 1 МБ каждая и ≤ 5 МБ все.
  Замер после каждого шага: `?perf` на реальном телефоне.
- **Остаётся под запретом — это закон и правило Space Apps, не дизайн:** логин с именем, фото лица и «AI-лицо»
  ребёнка. О детях ничего не уходит с устройства. Вместо этого: позывной на выбор (Lochin, Yulduz, Humo) + нашивка;
  прогресс хранится на устройстве (уже работает).

### Локальная работа — до любых новых коммитов

В `main` уже пришли движок, сцена, интерфейс и данные. У кого много несохранённой работы:
`git add -A && git commit -m "wip: <что>"` → `git push -u origin <имя>/work` (своя ветка) → написать Шохжахон-аке,
он сольёт. Так ничья работа не потеряется в конфликте.
