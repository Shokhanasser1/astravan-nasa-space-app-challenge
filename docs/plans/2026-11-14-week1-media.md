# Week 1 Media Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bundle the real SDO Sun (before and at the X1.0 peak) and the GIBS Earth for 25–31 Oct 2021, plus that week's sky positions.

**Architecture:** One Python script (stdlib + Pillow) with pure helpers (tested with `unittest`) and a thin network/convert layer; outputs WebP files and a manifest into `public/data/media/2021-10-25/`, and `src/engine/sky.json` from the concept table.

**Tech Stack:** Python 3 (`urllib`, `json`, Pillow WebP), Node check script (`npm run check`).

**Spec:** `docs/specs/2026-11-14-week1-media.md`

## Global Constraints

- Each WebP ≤ 150 KB; week total ≤ 1 MB.
- SDO: AIA 131 Å, 1024 px; peak frame nearest 2021-10-28 15:35Z within ±15 min; "before" = latest frame ≤ 14:17Z (flare begin 15:17Z − 60 min).
- GIBS layer: `VIIRS_SNPP_CorrectedReflectance_TrueColor` for dates ≥ 2016-01-01, else `MODIS_Terra_CorrectedReflectance_TrueColor`; request 2048×1024 JPEG, save 1024×512 WebP.
- Credit lines verbatim: "Courtesy of NASA/SDO and the AIA, EVE, and HMI science teams." and "NASA EOSDIS GIBS / Worldview".
- No API key. Raw downloads only in `scripts/data/raw/` (git-ignored). Run Python with `-I`.

## Review Focus

- SDO day listing has no frame in the window → script exits non-zero, writes nothing (test in Task 1).
- GIBS answers HTTP 200 with an XML/HTML error body instead of an image → rejected by magic-byte check (test in Task 1).
- A date before 2016 picks MODIS, from 2016 picks VIIRS (test in Task 1).
- Re-run is deterministic: same listing → same chosen frames (test in Task 1).
- Network hiccup → up to 3 retries with backoff, then a clear error naming the URL (Task 2, manual).
