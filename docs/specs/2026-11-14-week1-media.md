# Spec: real Sun and Earth media for mission 1 (week 2021-10-25)

Owner: Claude (data lane). Consumers: Shoxjahon aka (scene: Earth globe, wrist tablet), Asilbek (truth screen).
Sources: concept 3.0 §03 (moment 5 "real flare", moment 3 "Earth of that day"), §05 (sky table), §06 (truth
sequence); developer guide §02 (data is bundled, no server); `docs/DATA.md`.

## Goal

Ship, inside the build, the real Sun and the real Earth of the first mission week (25–31 Oct 2021, always the
first mission per the scenario), plus that week's sky positions, so the scene and truth screen can show them offline.

## Inputs

- Flare: DONKI FLR, X1.0, begin 2021-10-28 15:17Z, peak 15:35Z (checked 14 Nov via CCMC).
- SDO browse archive `https://sdo.gsfc.nasa.gov/assets/img/browse/2021/10/28/`, AIA 131 Å, 1024 px
  (`YYYYMMDD_HHMMSS_1024_0131.jpg`).
- GIBS WMS `https://gibs.earthdata.nasa.gov/wms/epsg4326/best/wms.cgi` true colour, one image per day 25–31 Oct.
  Layer: `VIIRS_SNPP_CorrectedReflectance_TrueColor` for dates from 2016 (fewer gaps), `MODIS_Terra_…` before.
- Sky values: concept 3.0 §05 table (team's PyEphem computation, 12:00 UTC, south pole site).

## Outputs

| File | Content |
|---|---|
| `public/data/media/2021-10-25/sdo-peak.webp` | SDO frame nearest 15:35Z (within ±15 min), 1024 px |
| `public/data/media/2021-10-25/sdo-before.webp` | Latest SDO frame at least 60 min before flare begin (≤ 14:17Z) |
| `public/data/media/2021-10-25/earth-YYYY-MM-DD.webp` ×7 | GIBS true colour, equirectangular, 1024×512 |
| `public/data/media/2021-10-25/manifest.json` | For every file: source URL, original file name/time, download date, label `measured`, credit line |
| `src/engine/sky.json` | `{ site, sun_el_deg: 1.5, weeks: { "2021-10-25": [7 × { day, sun_az_deg, earth_el_deg, earth_phase }] } }` |
| `scripts/data/fetch_media.py` + `scripts/data/test_fetch_media.py` | Reproducible fetch/convert; unit tests for the pure parts |

Sky values for 2021-10-25 (concept 3.0 §05): day 1–7 Sun azimuth 304, 292, 280, 268, 256, 244, 232°;
Earth above horizon 2.7, 3.9, 5.0, 5.8, 6.4, 6.8, 6.7°; Earth lit fraction 0.20, 0.28, 0.37, 0.47, 0.56, 0.66, 0.76.
Label `computed`; source "PyEphem, 12:00 UTC, observer at the lunar south pole; check against JPL Horizons".

## Acceptance

1. Two SDO and seven Earth WebP files exist; each ≤ 150 KB; week total ≤ 1 MB (phone budget, PWA precache).
2. `manifest.json` names every file with its exact source URL and the credit lines
   ("Courtesy of NASA/SDO and the AIA, EVE, and HMI science teams."; "NASA EOSDIS GIBS / Worldview").
3. Re-running the script produces the same files (deterministic frame choice), and it fails loudly — no file
   written — if a source returns an error page instead of an image or no frame is within the window.
4. `npm run check` passes with `sky.json` (7 days for the week); `npm run verify` stays green.
5. No API key used or stored (SDO and GIBS need none). Raw downloads stay in git-ignored `scripts/data/raw/`.

## Out of scope

Other 13 weeks (after the team's `weeks.json`/`sky.json` land), wiring the images into the scene (lane C) or the
truth screen (lane D), JPL Horizons cross-check (separate task).
