шлема, без всплывающих окон · три показателя: Энергия, Воздух и вода, Доза · уровни ★/★★/★★★ · буря невидима

голоса только взрослые или `speechSynthesis` · ничего о детях не уходит с устройства.

## 5. Как работаем (подробно — `CLAUDE.md`)

Своя папка, свой файл строк, `git pull --rebase` перед каждым push, `npm run verify` зелёный, маленькие коммиты.
Задача больше одного файла: спецификация `docs/specs/` → план (`writing-plans`) → TDD → `verification-before-completion`.
Изменение чужого файла — только через владельца.
